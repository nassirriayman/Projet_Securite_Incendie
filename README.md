# Qualiconsult Habitations — Sécurité incendie

Application d’aide à l’analyse réglementaire des bâtiments d’habitation selon l’arrêté du 31 janvier 1986 modifié.

## Fonctions principales

- classement automatique du bâtiment ;
- onze modules d’analyse réglementaire ;
- suivi des conformités et non-conformités ;
- sauvegarde locale des réponses ;
- rapport imprimable en PDF ;
- interface adaptée aux ordinateurs, tablettes et mobiles.

## Développement local

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

Le workflow GitHub Actions publie automatiquement le dossier compilé sur GitHub Pages après chaque mise à jour de la branche `main`.
